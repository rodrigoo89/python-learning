# Python Learning

Ejercicios y proyectos del curso **"Python TOTAL - Programador Avanzado en 16 días"**, organizados día por día. Este repo funciona como bitácora de aprendizaje: cada carpeta corresponde a un día del curso, con los ejercicios y prácticas que fui resolviendo.

## Contenido por día

| Carpeta | Temas |
|---|---|
| `dia2` | Variables, tipos de datos, operadores, formateo de cadenas, redondeo |
| `dia3` | Listas, tuplas, diccionarios, sets, slicing, métodos de string |
| `dia4` | Control de flujo, loops (`for`/`while`), comprensión de listas, `match`, `zip`, `enumerate` |
| `dia5` | Funciones, `*args` y `**kwargs`, interacción entre funciones |
| `dia6` | Manejo de archivos, `pathlib`, proyecto: administrador de recetas |
| `dia7` | Programación orientada a objetos: clases, atributos, métodos, herencia, polimorfismo. Proyecto: cuenta bancaria |
| `dia8` | Módulos y paquetes, manejo de errores, generadores, decoradores |
| `Proyectodia8` | Práctica adicional de módulos e imports |
| `dia9` | `os`/`shutil`, expresiones regulares, `collections`, `math`, fecha/hora, compresión de archivos |
| `dia10` | Proyecto con `pygame`: juego simple con sprites, colisiones y audio |
| `dia11` | Web scraping con `requests` y BeautifulSoup |
| `dia12` | **Proyecto: Control de Finanzas Personales** — app con Streamlit (CRUD de transacciones, filtros, dashboard de métricas, gráficos, import/export CSV, persistencia en disco, refactorizada a POO) |
| `Recetas` | Datos de ejemplo usados en el proyecto de administrador de recetas (día 6) |

## Sobre el proyecto del día 12

Es el proyecto más completo del curso hasta el momento: una app de finanzas personales construida con Streamlit y pandas, con filtros por categoría y fecha, dashboard de métricas, gráficos, importación/exportación de CSV y persistencia de datos. Para verlo en detalle o ejecutarlo de forma independiente, hay una versión dedicada en [control-finanzas-streamlit](https://github.com/rodrigoo89/control-finanzas-streamlit).

## Stack

Python 3.12, con librerías vistas a lo largo del curso: `pandas`, `streamlit`, `pygame`, `requests`, `beautifulsoup4`, `openpyxl`, entre otras.
